# 🖊️ Part 1: Handwritten Digit Recognition using CNN

A deep learning project to classify handwritten digits (0-9) from the popular MNIST dataset using a Convolutional Neural Network (CNN).

## 📚 Dataset
- **MNIST Dataset** (70,000 grayscale images of handwritten digits)
- 28x28 pixels per image
- Loaded via TensorFlow Keras

## 🚀 Features
- ✅ **2 Convolutional Layers**
- ✅ Max Pooling for dimensionality reduction
- ✅ Dense layers for classification
- ✅ Achieves **~99%** accuracy on training data

## 💻 Technologies Used
- Python
- TensorFlow / Keras
- Matplotlib, NumPy
- scikit-learn (for confusion matrix)
